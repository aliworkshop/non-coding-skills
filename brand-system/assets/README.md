Until they exist, use the brand name set as plain text (`--font-display`, weight 700)
where a logo would go, and don't invent a mark.

## Conventions

- Dark-variant logo is the default on dark surfaces; light variant only on light surfaces.
- Never stretch, recolor, shadow, or overlay the logo. On a busy photo, put it on a flat surface first.
- Partner or client logos are shown only with permission, rendered monochrome:
  `filter: brightness(0) invert(1); opacity: 0.4`.
